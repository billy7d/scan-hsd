## Cài lại app trên iPhone (Apple ID miễn phí)

App ký bằng Apple ID miễn phí chỉ chạy được 7 ngày. Hết hạn thì cắm iPhone vào Mac, mở khoá máy rồi chạy:

```bash
cd ~/Documents/KhoAnDam/flutter_app && flutter build ios --release
cd ~/Documents/KhoAnDam/flutter_app && flutter install --release
```

Nếu mở app báo "Nhà phát triển không được tin cậy": vào **Cài đặt → Cài đặt chung → Quản lý VPN & thiết bị** → chọn tài khoản nhà phát triển → **Tin cậy**.
